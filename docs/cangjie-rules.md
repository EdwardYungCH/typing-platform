# 倉頡與速成取碼規則手冊

本手冊是平台中文課堂（拆字提示、例字、題目）的依據。規則以**第三代倉頡**為準，因為 Windows 內置的「微軟速成」和「微軟倉頡」都是三代。整理自五色倉頡／速成字典、hkcards.com 倉頡教學（三代）、cangjieking.com 等教學，例字的碼已用本專案碼表逐一核對；三代與五代有別的地方另外註明。

---

## 1. 基本概念

| 名稱 | 說明 |
|---|---|
| 倉頡字母（字根） | 24 個，分四類：哲理類 日月金木水火土（A–G）、筆劃類 竹戈十大中一弓（H–N）、人身類 人心手口（O–R）、字形類 尸廿山女田卜（S–W、Y）。 |
| 難（X） | 不是字根，是「難字」鍵，代替太瑣碎、難拆的部分（見第 6 節）。 |
| Z | 倉頡用作標點／重複鍵，速成不用。 |
| 輔助字形 | 字母的變形（旋轉、增減筆劃）或同類延伸，例如 氵＝水、扌＝手、亻＝人、宀＝十、辶＝卜、艹＝廿、冂冖爫＝月、灬＝火。看到輔助字形就按它所屬的字母鍵。 |
| 倉頡碼 | 每字 1 至 5 碼。 |
| 速成碼 | 倉頡碼的**第一碼和最後一碼**，最多 2 碼；單碼字只有 1 碼。 |

筆劃類字母對應的基本筆劃：竹＝斜（撇）、戈＝點、十＝交（十字交叉）、大＝叉（撇捺交叉）、中＝縱（豎）、一＝橫、弓＝鉤。

**輔助字形單獨成字時不是一碼**（除非簡單到不能再拆）。例如 又＝弓大、小＝弓金、士＝十一、工＝一中一、八＝竹人、匕＝山竹、七＝十山、乙＝弓山、冂＝中尸、冖＝戈弓、宀＝戈月、广＝卜竹、厂＝一竹、艹＝十十、囗＝月一、亠＝戈一（微軟倉頡作戈卜）。只有 丿＝竹、丶＝戈、丨＝中、乂＝大 這類單筆劃形狀才取一碼。平台的「輔助字形」課必須提醒學生這一點（例如「又」作部件按 E，但單獨打「又」字是 N K）。

## 2. 取碼次序

**由上而下、由左而右、由外而內。** 先用這個次序切分，再逐個部件取碼。

- 一個字可以用到多於一種次序：唱 ＝ 先左右（口｜昌），再把昌上下切（日、日）→ 口日日。
- 筆順和取碼次序有衝突時，以取碼次序為準：肉 按筆順先寫 冂，但取碼由上而下 → 人月人。
- 右上角的一點通常是第一碼：求 ＝ 戈十水，我 ＝ 竹手戈（左上一撇是竹）。

## 3. 連體字與分體字（決定取幾碼）

### 3.1 連體字（整體字）
筆劃交連、整個字是一體，不能拆成字首和字身。

- 最多 **4 碼**。4 碼或以下全取；多於 4 碼取 **首、二、三、尾**。
- 例：鳥 竹日卜火（原本 竹日卜尸火，省去第四碼尸）、步 卜中一竹、雨 一中月卜、馬 尸手尸火、真 十月一金、我 竹手戈、求 戈十水、申 中田中、事 十中中弓、力 大尸、太 大戈、早 日十、白 竹日。
- 判斷：橫筆與豎／斜筆相交或相連，令部件分不開，就是連體（車、直、世、走都是）。

### 3.2 分體字（組合字）
可以切成**字首**和**字身**。

- **字首**：按取碼次序，第一個能單獨切出的部分（左、上或外）。其餘全部是**字身**。
- 字首最多 **2 碼**：多於 2 碼取 **首、尾**。
- 字身最多 **3 碼**：多於 3 碼取 **首、二、尾**。
- 全字最多 5 碼。

| 結構 | 例 |
|---|---|
| 上下型 | 字 十弓木（字首宀＝十，字身子＝弓木）、雪 一月尸一 |
| 左右型 | 俗 人金人口、理 一土田土、訓 卜口中中中（言取首尾卜口；川三豎全取） |
| 外內型 | 通 卜弓戈月、圄 田一一口 |

**字身本身又是分體字**：字身再分「次字首」和「次字身」，兩者合共仍只有 3 碼。
- 次字首最多 2 碼（多於 2 取首尾）；次字身取剩下的碼。
- 次字首 1 碼 → 次字身 2 碼（首、尾）：傾、復、蓮。
- 次字首 2 碼 → 次字身 1 碼（尾）：語 卜口一一口（言＝卜口；吾：五＝一一，口＝口）、諧、儲。

**字首是看位置，不是看部首或字義。** 常見誤判：
參（上面小厶，不是厽）、疊（最上一個田）、脅（左上角力）、鵬（左邊月）、雌（左邊止）、翁（頂部八）、凳（上面癶）、麗（頂部兩橫）、剪（䒑）、馳（左右切：馬｜也）、駡（上下切：口口｜馬）。

### 3.3 速成的意義
速成碼＝倉頡碼首尾，所以：
- 連體字：首碼＝字的第一個部件，尾碼＝字的最後一個部件。
- 分體字：首碼＝**字首的第一個部件**，尾碼＝**字身的最後一個部件**（字身再分時，是次字身的最後部件）。
- 「首、二、三、尾」「首、尾」的省略不影響速成，但**包含省略**（第 4.5 節）和**例外字**（第 5、6、7 節）會改變尾碼或首碼，必須教。

## 4. 五個取碼原則（由上而下逐條套用）

### 4.1 精簡原則
有多種拆法時，取**碼數最少**的。注意是整個字的碼數，不是筆劃最少的部件。
- 王 ＝ 一土（不是一十一）；主 ＝ 卜土；耳 ＝ 尸十；青 ＝ 手一月（不是十十一月）；爭 ＝ 月尸木；表 ＝ 手一女；句 ＝ 心口（不是竹尸口）。

### 4.2 完整原則
碼數相同時，優先取**涵蓋筆劃較多**的字形；部件本身已是字根就整個取，不逐筆拆。
- 夫 ＝ 手人（不是十大）；生 ＝ 竹手一（不是竹十土）；毛 ＝ 竹手山；益 ＝ 廿金月廿；因 ＝ 田大（外框整個取田）。

### 4.3 字形特徵原則
保留能認出字形的特徵：分割點落在直筆上，不落在轉角；盡量不取重疊的字形。
- 九 ＝ 大弓（不是大山，不能把鉤切掉）；申 ＝ 中田中（不是中日／中田）；之 ＝ 戈弓人（不是卜竹人）。
- 同類字的共同特徵：馬 尸手尸火、鳥 竹日卜火，底部四點都是火。

### 4.4 部分省略原則
就是 3.1、3.2 的「首二三尾」「首尾」「首二尾」：超過限定碼數時省略中間。

### 4.5 包含省略原則（決定尾碼，速成必須教）
字首或字身的**最後一個部件被三面或四面包圍**，而且該字首／字身**超過限定碼數**時，省去被包圍的部件，**取外框作尾碼**。
- 外框字形共 9 個：囗、冂、コ、匚、廿、几、乃、凵、ク。
- 要**完全**被包圍才算；有任何部分突出框外就不省略。
- 同一個部件，單獨成字和作字首／字身時尾碼可以不同：

| 單獨成字（未超碼數，不省略） | 作字首／字身（超碼數，省略） |
|---|---|
| 母 田卜戈 | 侮 人人田卜、海 水人田卜 |
| 舟 竹月卜戈 | 船 竹卜金口 |
| 柬 木田火 | 欄 木日弓田 |
| 酉 一金田一 | 醫 尸水一金田、醜 一田竹山戈 |
| 多 弓戈弓戈 | 夠 弓弓心口 |
| 風 竹弓竹中戈 | 颱 竹弓戈口 |
| 肉 人月人 | 瘸 大大口月 |
| 高 卜口月口 | 搞 手卜口月 |

- 其他例：滿 水廿中月、急 弓一心、雨 一中月卜、雷 一月田、角 弓月土、瓦 一女弓戈、齒 卜一山人人、臣 尸中尸中、而 一月中中、爾 一火月大、尚 火月口。
- 不適用：謔 卜口卜心一（最後的一突出框外）。

## 5. 複合字（永遠只取首尾兩碼）

無論單獨成字、作字首或作字身，一律只取**首尾兩碼**。共 9 個，要死記：

| 複合字 | 碼 | 例字 |
|---|---|---|
| 門 | 日弓 | 問 日弓口、們 人日弓、間 日弓日 |
| 目 | 月山 | 眼 月山日女、相 木月山、冒 日月山 |
| 鬼 | 竹戈 | 塊 土竹戈、傀 人竹戈 |
| 鬥 | 中弓 | 鬧 中弓卜中月 |
| 虍 | 卜心 | 虎 卜心竹山、處 卜心竹水弓 |
| 隹 | 人土 | 雞 月大人土、售 人土口、推 手人土、進 卜人土 |
| 幾 | 女戈 | 幾 女戈竹戈、機 木女戈戈 |
| 阝 | 弓中 | 陳 弓中木田、隊 弓中廿心人 |
| 吂 | 卜口 | 贏 卜口月弓、嬴 卜口月卜弓 |

對速成的影響：複合字作字首時，速成首碼就是複合字的首碼（問＝日口）；作字身時，速成尾碼是複合字的尾碼（們＝人弓、相＝木山、推＝手土、陳＝弓田）。

## 6. 難字（用 X 代替難拆的部分）

| 類型 | 規則 | 例 |
|---|---|---|
| 首難尾 | 首、尾易取，中間難取 → 首 X 尾 | 身 竹難竹、慶 戈難水、龜 弓難山、鹿 戈難心、廌 戈難火、黽 口難山、兼 廿難金、姊 女中難竹、淵 水中難中 |
| 首難 | 首易取，尾難取 → 首 X | 臼 竹難、與 竹難卜金、興 竹難月金、兒 竹難竹山、叟 竹難中水、肅 中難、蕭 廿中難、齊 卜難、濟 水卜難、卍 弓難 |

對速成的影響：「首難」型的字，速成尾碼就是 X（齊＝卜難、肅＝中難、臼＝竹難、濟＝水難、蕭＝廿難）；「首難尾」型的字速成不會出現 X（身＝竹竹、慶＝戈水）。常用字中含難的約 89 個，平台第 7 課只教常見的幾個。

## 7. 特殊字（重疊字形先取觸發字形）

一般不取重疊的字形，但 **木、火、大、心（七形）、戈** 與其他字形重疊時，**先取這五個觸發字形，再取重疊在上面的字形**。

- 末 木十、東 木田、速 卜木中、秉 竹木中、錬 金木田
- 拳 火手手、捲 手火手山
- 夷 大弓
- 屯 心山、頓 心山一月金
- 彧 戈大口一

## 8. 特別的字首（複合字首）

這些部件作字首時，不按「第一個能切出的部分」，而是整個部件當字首，取其首尾兩碼：

|---|---|---|

## 9. 速成專屬規則

1. **只打首尾兩碼**，中間一律不理；單碼字（日、月、口、人、木、一、十、大…）只打一碼。
2. 兩個字根鍵之外，**不用按 Z**；難字 X 可以是尾碼。
3. 因為只有兩碼，同碼字極多（平均一組碼超過 100 字）：**打完碼後按數字 1–9 揀字；要的字不在這一頁，按空白鍵翻到下一頁**（微軟速成的做法，平台已按此實作）。
4. 常用字的候選位置是固定的，多打幾次就會記得；平台的常用字課按微軟速成的次序出題。
5. 中文標點：組字框空着時直接按 ， 。 、 ？ ！ 「 」 ： 對應的鍵。

### 速成學生最常犯的錯
- 把部首當字首（例如 鵬 先打朋、順 先打川）。
- 忘記包含省略，尾碼打了框內的筆劃（海 打成 水戈，應為 水卜）。
- 複合字作字身時尾碼打錯（推 打成 手戈，應為 手土；陳 打成 弓一，應為 弓田）。
- 輔助字形認錯鍵（氵不是 E 以外的鍵；忄是 P；衤是 L；礻是 Y；辶是 Y；爫 冂 冖 是 B）。
- 單獨成字的輔助字形只按一個鍵（又、小、士、工 都不是一碼）。
- 右上角的點（求、我、成）忘了是第一碼。

## 10. 三代與五代的差別（本專案碼表的注意事項）

- 微軟速成／微軟倉頡是**三代**。本專案的速成碼表（rime-ms-quick）跟隨微軟，選字次序也一樣。
- 本專案的倉頡全碼表（rime-cangjie）是**五代**。五代修改了部分字的中間碼和少數首尾碼，例如：鬼 五代 竹山戈（三代 竹戈，複合字）、產 五代 卜大一竹一（三代 卜竹竹手一）、兔 五代 弓日竹戈（三代 弓山戈）、歷 五代 一竹木一（三代 一木卜中一）、應 五代 戈人土心（三代 戈土心）、彥、魔、醜、腐、贏。
- 做法：建碼表時只保留**五代首尾碼跟微軟速成相同**的字的全碼（約 380 字不符，已剔除，這些字只顯示速成碼不顯示全碼）；雙色拆碼圖也只在首尾碼核對一致時才上色。因此平台顯示的「倉頡拆法」中間碼可能與三代略有不同，但首尾碼（即速成碼）一定正確。
- 「順」在部分三代教材作 竹中一月金（字首是一撇），但微軟速成是 中金（字首川），平台以微軟為準，不用它作例子。
- 以後如取得三代碼表（例如微軟倉頡匯出的碼表），只需替換 `tools/build_zh_codes.py` 的倉頡來源。

## 11. 課堂對應（平台應教甚麼）

| 課 | 規則 |

| 0 認識速成 | 第 1 節概念、第 9 節 1–3 |
| 1–6 字根課 | 24 字母、輔助字形（第 1 節），輔助字形單獨成字不是一碼 |
| 7 難字鍵與總複習 | 第 6 節（常見難字：齊 肅 臼 與 興 兒 身 慶） |

| 9 拆字（一） | 分體字字首／字身（第 3.2 節）、字首看位置不看部首、精簡／完整／字形特徵（4.1–4.3） |
| 10 拆字（二） | 輔助字形在首尾碼的位置；**應加入**：包含省略（4.5）、複合字（5）、特殊字（7）、特別的字首（8）的常用例 |
| 11 選字與標點 | 第 9 節 3–5 |
| 12–15 | 應用 |

待辦（按本手冊修正課堂）：
1. 第 9 課導覽加入「字首看位置」的易錯例（順、鵬、雌、翁）和右上角點為首碼（求、我、成）。
2. 第 10 課加入包含省略（海、船、滿、急、搞）、複合字作字身（推、進、陳、相、們、問）、特殊字（東、末、速、拳、夷）和特別字首（學、氣、應、感）的拆字題，提示文字要能解釋「為甚麼尾碼是這個」。
3. 拆字提示的「倉頡拆法」改為標明三代／五代可能不同，只保證首尾碼。
